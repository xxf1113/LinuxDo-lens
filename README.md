# LinuxDo Lens

LinuxDo 增强阅读 + AI 总结 - 油猴脚本，为 LinuxDo 论坛提供增强阅读体验和 AI 内容总结功能。

## 功能

- 增强阅读体验
- AI 网页内容总结
- 集成 AI 总结功能

## 文件说明

- `LinuxDo 增强阅读集成AI.user.js` - 油猴脚本主文件
- `LinuxDo 增强阅读.txt` - 增强阅读功能说明
- `AI网页内容总结.txt` - AI 总结功能说明

## 使用方法

1. 安装 Tampermonkey 浏览器扩展
2. 将 `LinuxDo 增强阅读集成AI.user.js` 安装为用户脚本
3. 访问 LinuxDo 论坛即可使用
