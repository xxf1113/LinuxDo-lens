# LinuxDo 增强阅读 + AI 总结

> 在 LINUX DO 列表页点击标题即可弹窗预览整帖，楼中楼展示、点赞、回复、收藏、原图灯箱一应俱全，并按真实阅读节奏上报已读进度——无需离开列表页，也无需反复返回。集成 AI 网页内容总结，一键总结帖子内容。

一个油猴（Tampermonkey）用户脚本，为 [LinuxDo 论坛](https://linux.do/) 提供增强的阅读体验和 AI 内容总结功能。

## 功能概览

### 增强阅读

| 功能 | 说明 |
|------|------|
| **弹窗预览整帖** | 在列表页点击标题即弹出完整帖子，无需跳转页面 |
| **楼中楼嵌套展示** | 基于嵌套树 API（`/n/-/`）递归渲染回复层级，还原真实讨论结构 |
| **点赞 / 回复 / 收藏** | 弹窗内直接对楼层点赞、回复、收藏帖子，支持楼中楼回复 |
| **Boost 气泡** | 发送和删除 Boost，气泡样式展示，支持 emoji |
| **原图灯箱** | 点击图片弹出全屏灯箱查看大图，支持 Esc 关闭 |
| **视频占位播放** | 帖子中的视频以占位图展示，点击后加载播放 |
| **KaTeX 公式渲染** | 自动渲染帖子中的 LaTeX 数学公式（行内 & 块级），优先复用站点 KaTeX，回退 CDN |
| **已读进度追踪** | 按真实阅读节奏（停留时长）上报 Discourse timings，与站点已读状态同步 |
| **楼层滑动跳转条** | 右侧仿原生楼层导航条，拖动或点击快速跳转任意楼层 |
| **双向懒加载** | 滚动到顶部/底部自动加载更多评论，保持滚动位置不跳动 |
| **通知直达定位** | 从通知面板点击回复链接，弹窗自动展开祖先链并高亮目标楼层 |
| **已读跳未读** | 列表页点击标题时自动跳转到第一条未读评论 |
| **图片粘贴上传** | 回复框支持 Ctrl+V 粘贴图片直接上传至 Discourse |
| **骨架屏加载** | 数据加载期间展示骨架屏动画，提升感知速度 |
| **OP / ME 标签** | 楼主标记 OP，当前用户标记 ME |
| **已删除评论占位** | 被删除的评论以半透明占位符显示 |

### AI 总结

| 功能 | 说明 |
|------|------|
| **一键总结** | 弹窗底部点击「AI总结」按钮，自动提取主贴及评论区内容并生成总结 |
| **内置 AI** | 无需配置 API Key 即可使用内置 AI 服务（开箱即用） |
| **自定义 AI** | 支持配置任意 OpenAI 兼容 API（DeepSeek、OpenAI、通义千问等） |
| **多配置管理** | 支持保存多套 AI 配置，一键切换 |
| **预设提示词** | 内置 10 种总结模板（主贴+评论总结、简短概括、通用总结、学术论文、新闻事件、时间轴、观点对比、深度分析、表格化、要点清单） |
| **Markdown 渲染** | 总结结果以 Markdown 格式渲染，支持表格、代码块、引用等 |
| **打字机效果** | 总结内容逐字流式展示 |
| **Token 估算** | 显示输入/输出 Token 估算值 |
| **复制 / 重新总结** | 一键复制总结内容或重新生成 |

## 安装方法

### 前置要求

- 浏览器：Chrome / Edge / Firefox 等现代浏览器
- 扩展：[Tampermonkey](https://www.tampermonkey.net/)（油猴）或 [Violentmonkey](https://violentmonkey.github.io/)（暴力猴）

### 安装步骤

1. **安装 Tampermonkey 扩展**  
   从浏览器应用商店安装 Tampermonkey。

2. **下载脚本文件**  
   从本仓库下载 `LinuxDo 增强阅读集成AI.user.js`。

3. **导入脚本**  
   - 方式一：在 Tampermonkey 仪表盘中点击「+」新建脚本，将文件内容粘贴进去并保存。  
   - 方式二：将 `.user.js` 文件拖入 Tampermonkey 已安装脚本的浏览器页面，确认安装。

4. **访问 LinuxDo**  
   打开 [https://linux.do](https://linux.do)，在列表页点击任意帖子标题即可弹出预览窗。

## 使用指南

### 基本操作

| 操作 | 效果 |
|------|------|
| **列表页点击标题** | 弹窗打开帖子，自动跳转到第一条未读评论 |
| **通知面板点击回复链接** | 弹窗打开并定位到对应楼层，高亮闪烁 |
| **搜索结果点击** | 弹窗打开帖子 |
| **Esc / 点击遮罩 / 点击 ×** | 关闭弹窗 |
| **点击图片** | 打开原图灯箱 |
| **点击视频占位图** | 加载并播放视频 |
| **拖动右侧楼层条** | 快速跳转楼层 |
| **滚动到顶部/底部** | 自动加载更多评论 |

### 弹窗底部操作栏

| 按钮 | 功能 |
|------|------|
| ❤️ 点赞 | 对楼主帖点赞/取消点赞 |
| 💬 回复 | 展开回复框，回复楼主 |
| 🚀 Boost | 给楼主发送 Boost |
| 🔖 书签 | 收藏/取消收藏帖子 |
| 🔗 打开原帖 | 新标签页打开原帖 |
| 💡 AI总结 | 打开 AI 总结面板 |

### 楼层操作

每条楼层右下角有三个按钮：

- **点赞**：对当前楼层点赞/取消
- **回复**：展开回复框，回复当前楼层（楼中楼）
- **Boost**：对当前楼层发送 Boost

回复框支持粘贴图片（Ctrl+V），自动上传并插入 Markdown 图片链接。

### 楼中楼

- 回复以嵌套树结构展示，层级缩进 + 左侧竖线
- 点击「展示更多回复」加载被折叠的子回复
- 多层楼中楼会递归展开祖先链

## AI 总结配置

### 使用内置 AI（零配置）

安装后无需任何配置即可使用内置 AI 总结功能。点击弹窗底部的「AI总结」按钮即可。

### 使用自定义 AI

1. 点击 AI 面板右上角的「⚙ 设置」按钮
2. 填写以下字段：

| 字段 | 说明 |
|------|------|
| **API URL** | OpenAI 兼容的 API 地址（无需 `/chat/completions` 后缀，脚本会自动补全） |
| **API Key** | 你的 API 密钥（留空则使用内置 AI） |
| **模型** | 模型名称，如 `deepseek-chat`、`gpt-4o` 等 |
| **最大 Token 数** | 生成上限，默认 5000 |
| **总结提示词** | 自定义提示词，或从预设模板选择 |

3. 点击「保存」

### 支持的 AI 服务示例

| 服务 | API URL | 模型示例 |
|------|---------|----------|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v4` | `glm-4` |

### 预设提示词模板

| 模板 | 适用场景 |
|------|----------|
| 主贴+评论总结 | 主贴要点 + 评论区整体观点综合（不逐条复述） |
| 简短概括 | 快速了解核心内容（200字以内） |
| 通用总结 | 全面总结主要观点和关键信息 |
| 学术论文总结 | 研究目的、方法、发现、结论 |
| 新闻事件总结 | 事件梗概、经过、影响、各方反应 |
| 时间轴梳理 | 按时间顺序整理事件脉络 |
| 观点对比 | 正反面对比分析 |
| 深度分析 | 表层信息、深层原因、影响和建议 |
| 表格化总结 | 提取重点整理成表格 |
| 要点清单 | 简洁要点列表，按重要性排序 |

### 多配置管理

- 在设置面板中可新建、切换、删除多套配置
- 配置存储在 Tampermonkey 的 `GM_setValue` 中，跨会话持久化

## 技术细节

### 架构

脚本由两个 IIFE（立即执行函数）模块组成：

1. **增强阅读模块**（第 1~2488 行）  
   负责弹窗 UI、嵌套树渲染、已读追踪、楼层导航、事件委托等。

2. **AI 总结模块**（第 2490~3030 行）  
   负责 AI 配置管理、内容提取、API 调用、Markdown 渲染、打字机效果。  
   通过 `window.__LDP_AI__.initAISummary()` 暴露给增强阅读模块调用。

### 关键 API

| API | 用途 |
|-----|------|
| `GET /n/-/{topicId}.json` | 嵌套树 API，获取话题的树形回复结构 |
| `GET /n/-/{topicId}/children/{postNumber}.json` | 获取指定楼层的直接子回复 |
| `GET /t/{topicId}.json` | 扁平流 API（用于通知跳转定位） |
| `GET /t/{topicId}/posts.json?post_ids[]=...` | 批量获取指定帖子 |
| `POST /topics/timings` | 上报已读进度 |
| `POST /post_actions` | 点赞/取消点赞 |
| `POST /posts` | 发表回复 |
| `POST /bookmarks` / `DELETE /bookmarks/{id}` | 收藏/取消收藏 |
| `POST /discourse-boosts/posts/{id}/boosts` | 发送 Boost |
| `DELETE /discourse-boosts/boosts/{id}` | 删除 Boost |
| `POST /uploads.json` | 上传图片 |

### 已读追踪原理

使用 `IntersectionObserver` 监测每条楼层在弹窗滚动区域内的可见性。当楼层可见面积 ≥ 50% 时开始累计停留时间，每秒 tick 一次。当停留时间超过阈值（1500ms）后，每 5 秒批量上报至 `/topics/timings`，与 Discourse 原生已读机制完全兼容。

### 楼层定位流程

1. 从通知链接解析出 `topicId` 和 `targetPostNumber`
2. 通过扁平流 API 加载目标楼层附近的数据
3. 递归展开目标楼层的祖先链（逐层调用 children API）
4. 滚动到目标楼层并高亮闪烁
5. 定位完成后开放双向懒加载

### 依赖

| 依赖 | 用途 | 加载方式 |
|------|------|----------|
| [markdown-it](https://github.com/markdown-it/markdown-it) 13.0.1 | AI 总结的 Markdown 渲染 | `@require` CDN |
| [KaTeX](https://katex.org/) 0.16.11 | 数学公式渲染 | 按需动态加载（优先站点资源，回退 CDN） |
